JEEP SAFARI MEDIA
=================

Put your own files in this folder with EXACTLY these names:

  jeep-safari.mp4           the jeep safari video (MP4 / H.264, ideally under 20 MB)
  jeep-safari-poster.jpg    optional: the still image shown before the video plays
  jeep-safari.jpg           the jeep safari photo (landscape, around 1600px wide)

They appear in the "See the ride" section of the Jeep Safari page.
Until a file exists, a tidy illustrated placeholder is shown instead.

Tips
----
* Keep the photo under about 300 KB (use squoosh.app) so the page stays fast.
* To change the file names or locations, edit  media  in  src/data/site.js
